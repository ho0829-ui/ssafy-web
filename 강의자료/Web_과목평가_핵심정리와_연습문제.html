TOPIC 01

Flex 교차축 정렬

Flex

align-items는 컨테이너 안의 아이템들을 교차축에서 정렬한다. 주요 값은 stretch, flex-start, center, flex-end, baseline. 기본값 stretch는 아이템의 교차축 크기가 auto일 때 늘린다.

/* 부모에 작성 */
.container {
  display: flex; height: 160px;
  align-items: center;
}

실수 포인트
row일 때 세로 정렬, column일 때 가로 정렬이다. align-content는 여러 줄의 배치다.

교재 L 57, 59
TOPIC 02

Box Model 너비 계산

Box·표시

안쪽부터 content → padding → border → margin. 테두리까지의 박스 너비와 바깥 여백까지 합한 너비를 구분한다. 수평 여백을 단순 합산하는 문제에서는 margin 좌우도 더한다.

/* content-box, 각 방향 동일 */
width: 200px; padding: 20px;
border: 5px solid; margin: 10px;
/* 테두리까지: 200 + 40 + 10 = 250px */
/* margin 포함: 250 + 20 = 270px */

실수 포인트
문제의 “너비”가 콘텐츠인지, 테두리까지인지, margin 포함인지 먼저 표시한다.

교재 H 73–80
TOPIC 03

자손·자식 선택자

선택자·상속

A B는 A 내부의 모든 깊이에 있는 B를 선택한다. A > B는 A의 직계 자식 B만 선택한다. 공백과 >는 서로 다른 결합자다.

<div class="box">
  <p>A</p>
  <section><p>B</p></section>
</div>
/* .box p   → A, B */
/* .box > p → A */

실수 포인트
자손은 직계 자식도 포함한다. 결합자 자체는 명시도를 올리지 않는다.

교재 H 43–48
TOPIC 04

box-sizing별 요소 너비

Box·표시

content-box의 width는 콘텐츠 너비다. border-box의 width는 콘텐츠·padding·border를 포함한다. 두 방식 모두 margin은 width 밖이다.

width: 100px; padding: 10px;
border: 2px solid; margin: 20px;
/* content-box: 테두리까지 124px */
/* border-box: 테두리까지 100px */
/* border-box: 콘텐츠는 76px */

실수 포인트
border-box에서 padding을 늘리면, 지정 너비가 충분한 조건에서는 콘텐츠가 줄어든다.

교재 H 80–84
TOPIC 05

content-box 너비 계산

Box·표시

테두리까지의 너비 = width + 좌우 padding + 좌우 border. 상하 padding은 가로 너비 계산에 넣지 않는다.

box-sizing: content-box;
width: 240px; padding: 10px 20px;
border: 3px solid;
/* 240 + 20×2 + 3×2 = 286px */

실수 포인트
padding: 10px 20px는 상하 10px, 좌우 20px다. 4개 값은 상→우→하→좌 순서다.

교재 H 78, 80–84
TOPIC 06

position: absolute와 문서 흐름

Position

absolute는 일반 문서 흐름에서 빠지므로 원래 자리를 남겨 두지 않는다. 형제 요소는 그 요소가 없어진 것처럼 일반 흐름에 따라 배치될 수 있다.

<div>A</div>
<div class="badge">B</div>
<div>C</div>
<style>
.badge { position: absolute; top: 0; }
</style>

실수 포인트
relative는 원래 공간이 남는다. absolute는 기준 조상 지정과 문서 흐름 이탈을 함께 생각한다.

교재 L 31–35
TOPIC 07

inline과 block 요소

Box·표시

block은 일반 흐름에서 새 줄을 만들며 보통 사용 가능한 너비를 채운다. inline은 문장 흐름 안에서 콘텐츠만큼 차지한다. 일반적인 비대체 inline(span 등)에는 width·height가 적용되지 않는다.

div { display: block; width: 180px; }
span { display: inline; }
.tag { display: inline-block;
       width: 100px; height: 32px; }

실수 포인트
inline-block은 줄 안에 놓이면서 크기 지정이 가능하다. img 같은 대체 요소에는 일반 span의 크기 규칙을 그대로 적용하지 않는다.

교재 L 8–24
TOPIC 08

position: fixed

Position

fixed는 일반 흐름에서 빠지고, 보통 뷰포트 기준으로 배치된다. 페이지를 스크롤해도 화면의 지정된 위치를 유지한다.

/* 화면 오른쪽 아래에 고정 */
.help {
  position: fixed;
  right: 20px; bottom: 20px;
}

실수 포인트
relative는 자기 원래 위치, absolute는 기준 조상, fixed는 보통 뷰포트. transform 등의 조상 효과가 없는 기본 상황을 가정한다.

교재 L 29–35
TOPIC 09

Flex 주축 정렬

Flex

justify-content는 주축의 여유 공간을 배분하고 정렬한다. flex-start, center, flex-end, space-between, space-around, space-evenly를 구별한다.

/* 부모에 작성 */
.container { display: flex;
  justify-content: space-between; }
/* 양 끝 여백 0, 아이템 사이 간격 동일 */

실수 포인트
space-around의 양 끝 간격은 내부 간격의 절반이고, space-evenly는 양 끝과 내부 간격이 같다.

교재 L 55, 59, 85
TOPIC 10

Bootstrap Grid gutter

Bootstrap

gutter는 컬럼 콘텐츠 사이의 간격이다. row에 gx-*를 쓰면 가로, gy-*는 세로, g-*는 양쪽 방향을 조정한다. 가로는 컬럼의 좌우 padding, 세로는 위쪽 margin을 활용한다.

<div class="row gx-0 gy-3">
  <div class="col-6">A</div>
  <div class="col-6">B</div>
</div>
<!-- gx-0: 가로 gutter 제거 -->

실수 포인트
g-*와 m-*, p-*를 혼동하지 않는다. 기본 가로 gutter는 1.5rem이며 g-0은 가로·세로 모두 0이다.

교재 R 29, 43–46
TOPIC 11

Reset CSS

시맨틱·방법론

브라우저마다 다른 기본 스타일을 일관된 기준으로 재설정한다. 기본 여백·제목 크기 등의 차이를 줄여 같은 출발점에서 디자인하기 위한 것이다. Bootstrap은 Reboot를 사용한다.

/* 기본 여백을 초기화하는 작은 예 */
body { margin: 0; }
/* Bootstrap의 Reboot 파일명 */
/* bootstrap-reboot.css */

실수 포인트
Reset은 브라우저 기본 스타일 차이를 줄이는 작업이다. 반응형 컬럼 배치나 CSS 상속 제거와는 다르다.

교재 B 19–24
TOPIC 12

CSS 상속 속성

선택자·상속

대표적인 기본 상속 속성은 color, font-family, font-size, text-align, visibility다. width, height, margin, padding, border, position은 기본 상속하지 않는다.

.parent { color: red; border: 1px solid; }
/* 자식은 글자색을 상속하지만
   테두리가 자동으로 생기지는 않는다. */

실수 포인트
자식에 직접 선언한 값이 있으면 단순 상속값보다 먼저 적용된다. 교재 p.87의 opacity 표기는 아래 “교재 보정 메모”를 확인한다.

교재 H 87–89
TOPIC 13

HTML5 시맨틱 태그

시맨틱·방법론

header: 소개·탐색 도움, nav: 주요 탐색 링크, main: 주요 내용, article: 독립 배포 가능한 콘텐츠, section: 주제별 구획, aside: 간접 관련 내용, footer: 구획의 꼬리말.

<main>
  <article>
    <h2>독립적인 게시글 제목</h2>
    <p>게시글 내용</p>
  </article>
</main>

실수 포인트
div와 span은 일반적인 컨테이너다. 태그는 원하는 모양보다 콘텐츠의 역할에 맞춰 선택한다.

교재 B 45–51; H 30–31
TOPIC 14

Bootstrap 반응형 Grid

Bootstrap

col-12 col-md-6 col-lg-4는 768px 미만에서 12칸, 768px 이상에서 6칸, 992px 이상에서 4칸이다. 해당 분기점 이상에서 적용되며 더 큰 분기점 선언이 있으면 바뀐다.

<div class="row">
  <div class="col-12 col-md-6 col-lg-4">
    콘텐츠
  </div>
</div>
<!-- 동일한 컬럼 반복 시 한 줄 1→2→3개 -->

실수 포인트
sm 576 / md 768 / lg 992 / xl 1200 / xxl 1400px. xs에는 접두사를 붙이지 않으므로 col-xs-6이 아니라 col-6이다.

교재 R 48–57
TOPIC 15

Bootstrap 버튼

Bootstrap

기본 클래스 btn과 변형 클래스 btn-primary 등을 조합한다. btn-danger는 위험 동작, btn-success는 성공 의미. btn-outline-*는 테두리형, btn-sm·btn-lg는 크기다.

<button type="button"
  class="btn btn-primary">저장</button>
<button type="button"
  class="btn btn-outline-danger btn-sm">
  삭제
</button>

실수 포인트
class 속성에는 점 없이 btn을 쓴다. CSS 선택자로 적을 때는 .btn이다. 교재의 btn-blue는 OOCSS 예제의 사용자 정의 클래스다.

교재 B 32, 42, 58; 공식 Buttons 보충
TOPIC 16

Bootstrap Spacing

Bootstrap

형식은 {m 또는 p}{방향}-{크기}. m은 margin, p는 padding. t 위·b 아래·s 시작·e 끝·x 좌우·y 상하·생략은 네 방향. LTR에서 s는 왼쪽, e는 오른쪽이다.

m-5   /* 네 방향 margin: 3rem */
px-3  /* 좌우 padding: 1rem */
mt-2  /* 위 margin: 0.5rem */
mx-auto /* 좌우 margin: auto */
/* 반응형 예: mt-md-3 */

실수 포인트
크기 0/1/2/3/4/5 → 0/.25/.5/1/1.5/3rem. m-5는 5px가 아니다. auto는 margin에 사용한다.

교재 B 15–17
TOPIC 17

Bootstrap Grid 컬럼 배치

Bootstrap

container → row → col 구조이며 한 행을 12칸으로 나눈다. col-5는 5/12 너비. 숫자 없는 col은 남는 공간을 균등하게 나눈다. 합이 12를 넘으면 다음 컬럼이 다음 줄로 넘어간다.

<div class="container">
  <div class="row">
    <div class="col-5">5칸</div>
    <div class="col-7">7칸</div>
  </div>
</div>

실수 포인트
col-5 3개면 첫 줄 2개·다음 줄 1개다. offset-3은 앞쪽 3칸 여백. 중첩 row는 자기 부모 컬럼 안에서 다시 12칸으로 나뉜다.

교재 R 26–41, 69–70
TOPIC 18

요소 숨기기

Box·표시

display: none은 표시와 레이아웃 공간을 없앤다. visibility: hidden은 보이지 않지만 자리를 유지한다. opacity: 0도 자리를 유지하며 투명할 뿐 클릭 대상이 될 수 있다.

.a { display: none; }
.b { visibility: hidden; }
.c { opacity: 0; }

실수 포인트
교재의 직접 예시는 display: none이다. hidden·opacity 비교는 토픽 이해를 위한 보충 설명이다.

교재 L 23–24; H 87
TOPIC 19

content-box 구성 요소

Box·표시

콘텐츠 박스(content box) 자체는 내용 영역이다. CSS 박스 모델은 content, padding, border, margin으로 설명한다. box-sizing: content-box는 width·height를 내용 영역에 적용하는 계산 방식이다.

/* content-box: width는 내용만 */
.box { box-sizing: content-box;
       width: 100px; padding: 10px; }
/* border가 0이면 테두리까지 120px */

실수 포인트
“content-box의 width에 padding이 포함된다”는 틀리다. “박스 모델의 구성 요소”라는 질문과 혼동하지 않는다.

교재 H 73–84
TOPIC 20

CSS 캐스케이드

선택자·상속

여러 선언이 충돌할 때 적용할 값을 결정하는 과정이다. 교재의 기본 문제는 중요도 → 명시도 → 선언 순서로 판단한다. 조건과 명시도가 같으면 나중 선언이 이긴다.

p { color: red; }
p { color: blue; }
/* 동일 명시도: blue */
/* HTML의 class 나열 순서는 기준이 아님 */

실수 포인트
“무조건 마지막 CSS가 적용된다”는 틀리다. 이 자료의 문제는 같은 작성자·같은 레이어이며 애니메이션 등은 없다고 가정한다.

교재 H 50–56
TOPIC 21

flex-grow 공간 분배

Flex

flex-grow는 남는 공간의 배분 비율이다. 기본 크기가 있는 경우 최종 너비 자체가 grow 비율과 같지는 않다. 기본값은 0이다.

/* 컨테이너 600px, 초기 너비 각 100px */
/* grow: 1, 1, 0, 2 / 여백·테두리 없음 */
/* 남는 공간: 600 - 400 = 200px */
/* 추가 너비: 50, 50, 0, 100px */
/* 최종 너비: 150, 150, 100, 200px */

실수 포인트
gap·padding·border·margin 및 최소/최대 크기 제한이 없는 단순 조건이다. 남는 공간부터 계산한다.

교재 L 60–63
TOPIC 22

z-index와 position

Position

z-index는 겹친 요소의 앞뒤 쌓임 순서를 조절한다. 같은 쌓임 맥락에서 값이 큰 요소가 앞에 온다. 일반적인 박스 문제에서는 static이 아닌 position과 함께 사용한다.

.a { position: absolute; z-index: 2; }
.b { position: absolute; z-index: 5; }
/* 같은 쌓임 맥락이면 b가 앞 */

실수 포인트
Flex·Grid 아이템은 position: static이어도 z-index가 적용될 수 있다. 다른 쌓임 맥락의 값을 단순 비교하지 않는다.

교재 L 37–39
TOPIC 23

position 기준점

Position

static: 일반 흐름. relative: 자기 원래 자리. absolute: 보통 position이 static이 아닌 가장 가까운 조상. fixed: 보통 뷰포트. sticky: 스크롤 기준에 따라 달라진다.

.card { position: relative; }
.badge { position: absolute;
         top: 0; right: 0; }
/* .card 안 오른쪽 위에 .badge 배치 */

실수 포인트
교재는 “가장 가까운 relative 부모”로 단순화한다. 조상은 absolute·fixed·sticky도 기준이 될 수 있다.

교재 L 29–35
TOPIC 24

CSS 상대 단위

선택자·상속

rem은 루트 html의 글자 크기. font-size에 쓴 em은 부모 글자 크기. width·padding 등에 쓴 em은 해당 요소의 글자 크기를 따른다. %는 속성마다 기준이 다르다.

/* html:16px, 부모:20px */
.child { font-size: 1.5em; } /* 30px */
.other { font-size: 1.5rem; } /* 24px */
/* 1vw = 뷰포트 너비의 1% */
/* 1vh = 뷰포트 높이의 1% */

실수 포인트
width의 %는 보통 부모의 콘텐츠 너비가 기준이다. padding·margin의 %도 일반적인 가로쓰기에서 부모 너비 기준이다.

교재 H 60–68
TOPIC 25

position 속성 값

Position

static, relative, absolute, fixed, sticky를 정확히 쓴다. static이 기본값이다. absolute와 fixed는 일반 흐름에서 빠지고, relative와 sticky는 원래 공간을 유지한다.

.nav { position: sticky; top: 0; }
/* 스크롤 시 top: 0 경계에 도달하면
   포함 블록의 범위 안에서 달라붙는다. */

실수 포인트
sticky를 단순히 “항상 화면 고정”이라고 쓰지 않는다. top 같은 기준값과 스크롤·부모 범위가 중요하다.

교재 L 29–35
TOPIC 26

CSS 선택자 우선순위

선택자·상속

교재의 일반적인 충돌 문제: !important 선언 → 인라인 스타일 → ID → 클래스·속성·의사 클래스 → 요소·의사 요소. 동일 조건에서 같은 명시도라면 뒤의 선언을 쓴다.

/* 같은 요소를 선택한다고 가정 */
#title { color: red; }
.title { color: blue; }
h1 { color: green; }
/* ID 선택자의 red가 적용됨 */

실수 포인트
!important는 선택자가 아니라 선언의 중요도를 바꾸는 표시다. 클래스 속성에 이름을 쓴 순서는 우선순위와 무관하다.

교재 H 50–56, 91
TOPIC 27

Flex 여러 줄 정렬

Flex

align-content는 교차축에서 줄 묶음을 정렬하고 줄 사이 여유 공간을 분배한다. 교재 문제에서는 flex-wrap: wrap, 여러 줄, 교차축 여유 공간이 있는 조건을 확인한다.

.container { display: flex;
  flex-wrap: wrap; height: 300px;
  align-content: space-between;
}

실수 포인트
align-items는 각 줄 안 아이템 정렬이다. nowrap인 단일 줄 Flex 컨테이너에는 align-content가 효과를 내지 않는다.

교재 L 54, 56–59
TOPIC 28

시맨틱 태그와 검색 엔진

시맨틱·방법론

시맨틱 마크업은 콘텐츠의 역할과 구조를 드러내 검색 엔진·개발자·보조 기술이 문서를 이해하기 쉽게 한다. 예를 들어 h1은 큰 글자뿐 아니라 최상위 제목이라는 의미가 있다.

<!-- 시각적 크기만 지정 -->
<p style="font-size:32px">제목</p>
<!-- 제목의 의미까지 제공 -->
<h1>제목</h1>

실수 포인트
시맨틱 태그 사용만으로 검색 순위 상승을 보장하지 않는다. “구조와 의미를 이해하는 데 도움”으로 설명한다.

교재 H 30; B 45–51, 66
TOPIC 29

CSS 방법론

시맨틱·방법론

교재 핵심은 OOCSS(Object Oriented CSS). 원칙은 구조와 스킨 분리, 컨테이너와 콘텐츠 분리. 공통 모양을 재사용하고 위치에 대한 의존을 낮춰 유지보수를 쉽게 한다.

.button { padding: 10px 20px;
          border: none; } /* 공통 구조 */
.button-blue { background: blue; }
.button-red { background: red; }
/* class="button button-blue" */

실수 포인트
이 토픽은 교재의 OOCSS부터 공부한다. 버튼마다 공통 크기·여백을 반복 작성하는 방식은 재사용성이 떨어진다.

교재 B 53–58, 75
TOPIC 30

Flex 개별 아이템 정렬

Flex

align-self는 특정 아이템 하나의 교차축 정렬을 지정한다. 컨테이너의 align-items보다 해당 아이템에 우선 적용된다. 기본값 auto는 보통 부모 align-items 설정을 따른다.

.container { display: flex;
  height: 140px; align-items: flex-start; }
.special { align-self: flex-end; }

실수 포인트
align-self는 아이템에, align-items는 부모에 작성한다. Flex에서 justify-self로 주축 개별 정렬을 하지는 않는다.

교재 L 57–59
TOPIC 31

Flex 주축과 교차축

Flex

flex-direction이 주축을 결정한다. 기본 row는 가로 주축·세로 교차축, column은 세로 주축·가로 교차축이다. reverse는 주축의 시작과 끝 방향을 뒤집는다.

/* 일반적인 가로쓰기·왼쪽→오른쪽 기준 */
.container { display: flex;
  flex-direction: column;
  justify-content: center; /* 세로 중앙 */
  align-items: center; }  /* 가로 중앙 */

실수 포인트
“justify-content는 항상 가로 정렬”은 오답이다. 방향을 확인한 다음 주축·교차축을 판단한다.

교재 L 45–59
TOPIC 32

CSS 명시도

선택자·상속

선택자 명시도는 (ID 수, 클래스 계열 수, 요소 계열 수)를 왼쪽부터 비교한다. 클래스 계열에는 속성·의사 클래스, 요소 계열에는 의사 요소가 포함된다.

/* #app .card p → (1, 1, 1) */
/* .wrap .card p → (0, 2, 1) */
/* div > p      → (0, 0, 2) */
/* *            → (0, 0, 0) */

실수 포인트
자리 올림이 있는 십진수 점수가 아니다. 클래스가 많아도 ID 한 개를 이기지 못한다. *, 공백, >는 명시도에 더하지 않는다.

교재 H 43–56, 91

교재 보정 메모

교재의 간략한 설명과 실제 CSS 규칙이 다른 부분입니다. 본문과 연습문제는 아래 구분을 반영했습니다.

H p.87 · opacity — 교재는 상속 속성 목록에 넣었지만, 실제로는 기본 상속하지 않습니다. 부모와 자식이 묶여 함께 투명해 보이는 효과를 상속과 구별하세요. MDN 확인

L p.32 · absolute 기준점 — 교재의 “가장 가까운 relative 부모, 없으면 body”는 단순화된 설명입니다. 일반적으로 static이 아닌 가장 가까운 조상의 padding box가 기준이며, 없으면 초기 컨테이닝 블록이 기준입니다. transform 등이 있는 조상도 기준을 만들 수 있습니다. MDN 확인

L p.38 · z-index — 교재는 static이 아닌 요소에 적용한다고 설명합니다. Flex·Grid 아이템은 static이어도 적용될 수 있습니다. 비교 단위도 단순한 “같은 부모”가 아니라 쌓임 맥락입니다. MDN 확인

H p.62 · em — font-size에 쓰면 부모 글자 크기, width·padding 등에 쓰면 해당 요소의 글자 크기가 기준입니다. MDN 확인

R p.50 · 분기점 수치 — 표의 768px 같은 breakpoint와 720px 같은 container max-width는 서로 다릅니다. 반응형 클래스의 조건은 화면 너비 breakpoint를 봅니다.

버튼·숨김 보충 — 버튼은 B p.42의 btn btn-primary 예시에 공식 문서의 outline·size를 보충했습니다. B p.58의 btn-blue는 사용자 정의 클래스입니다. Bootstrap Buttons · visibility
